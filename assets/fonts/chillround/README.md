# ChillRoundF v3.200

Source: https://github.com/Warren2060/ChillRound/releases/tag/v3.200

Regular and Bold are converted from the official release's TTF files to WOFF2 using fontTools 4.60.2 and Brotli 1.2.0. Full character coverage is preserved. The fonts are served from this site to avoid cross-origin loading restrictions. No `local()` override is used, ensuring visitors receive the same font version.
